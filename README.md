# StudyBridge

Admissions platform for students going to study in India, Nepal and Bangladesh.

This repository holds the demo front end: a static page with no build step.

## What is on the page

- **College finder**: filter by country, course, branch, level, city and yearly budget.
- **Currency switch**: costs in INR, NPR, BDT or USD.
- **Comparison table**, **how it works** and **services**.
- **Mentors**: sample mentor cards with a call request button.
- **Free counselling form**.

## Current limits

- College costs, exchange rates and mentor profiles are sample data, not confirmed figures.
- The counselling form saves to the visitor's browser only. It is not connected to a backend yet.

## Run it

Open `index.html` in a browser.

## Deploy on Vercel

Import this repository, choose Framework Preset "Other", leave the build command empty and deploy.
